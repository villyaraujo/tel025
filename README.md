# TEL025 – Resumos e Quiz
Site estático (HTML + JS + `questions.json`).

## Publicar no GitHub Pages
1. Crie um repositório e envie `index.html`, `questions.json` e `README.md`.
2. Settings → Pages → Source: `main` / root → Save.
3. Acesse `https://SEU_USUARIO.github.io/NOME_DO_REPO/`.

Teste local: `python3 -m http.server` e abra http://localhost:8000
