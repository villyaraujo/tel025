Protocolos e serviços

  • ARP: IP → MAC (quadro tipo 0x806); gateway: saída da rede local
  • DHCP: IP automático · DNS: nome → IP (UDP/TCP 53) · FTP: transferência de arquivos
  • ICMP: ping/erros; TTL decrementa a cada roteador
  • TFTP UDP 69 · SNMP UDP 161

IPv4 e sub-redes

  • 32 bits, 4 octetos. Classes: A 1–126 (/8), B 128–191 (/16), C 192–223 (/24), D multicast, E reservada
  • Hosts úteis = 2n − 2 (n = bits de host)
  • Sub-redes = 2bits emprestados
  • Passo da sub-rede = 256 − octeto da máscara

✍️ Como calcular na mão (sub-redes e hosts)

  1. Máscara → CIDR: conte os bits 1. 255.255.252.0 = 8+8+6+0 = /22. Valores de octeto: 128, 192, 224, 240, 248, 252, 254, 255 (1, 2, 3, 4, 5, 6, 7, 8 bits 1).
  2. Bits de host: h = 32 − prefixo (os bits 0 da máscara). Ex.: /22 → h = 10.
  3. Hosts válidos: 2h − 2 (tira o endereço de rede e o de broadcast). /22 → 2¹⁰ − 2 = 1022.
  4. Sub-redes (método da apostila): 2n, em que n = bits 1 no octeto onde aparece o primeiro 0 da máscara. /22 → octeto 252 = 11111100 → n = 6 → 2⁶ = 64. /18 → 192 → n = 2 → 4. /27 → 224 → n = 3 → 8.
  5. Salto (tamanho do bloco): 256 − valor do octeto “quebrado”. /27 → 256 − 224 = 32. Redes: .0, .32, .64, .96, .128, .160, .192, .224.
  6. Rede do host: o maior múltiplo do salto que seja ≤ ao octeto do host. Broadcast = próxima rede − 1. Hosts = rede + 1 até broadcast − 1.

Exemplo 192.168.15.101/27 (da apostila): salto 32 → 96 ≤ 101 < 128 → rede 192.168.15.96, broadcast .127, hosts .97 a .126 (30 hosts).

Exemplo 10.228.8.0/22: máscara 255.255.252.0 → salto 4 no 3º octeto (256 − 252). Rede 10.228.8.0 → próxima 10.228.12.0 → broadcast 10.228.11.255, hosts 10.228.8.1 a 10.228.11.254.

  • Uso da máscara: separa rede (bits 1) de host (bits 0). IP AND máscara = endereço de rede. Dois hosts só se falam direto (sem roteador) se tiverem o mesmo endereço de rede. Ex.: 172.16.15.100/18 e 172.16.66.101/18 estão em redes diferentes.

VLAN e Trunk

  • VLAN = domínio de broadcast lógico; separa redes no mesmo switch
  • Porta access (switchport mode access + access vlan N) × trunk (switchport mode trunk, 802.1Q)
  • DTP negocia trunk (dynamic auto/desirable)
  • Comunicação entre VLANs exige camada 3 (SVI/roteador)

STP / RSTP / VTP

  • STP evita loops bloqueando links redundantes; RSTP converge mais rápido
  • VTP propaga VLANs: modos Server, Client, Transparent

Switch L2 × L3 na hierarquia Cisco

  • Switches gerenciáveis: L2 (comutação de quadros) e alguns L3 (roteamento IP)
  • Usados na agregação/acesso de redes grandes, ou como Core em redes menores
  • L2: EtherChannel, STP, Root-Guard, BPDU Guard · L3: redundância com VRRP
  • SVI: interface virtual da VLAN com IP → gerência remota (o switch vira host) e roteamento entre VLANs

Ferramentas

  • ping (ICMP), traceroute, mtr, route, arp
  • Sniffers: tcpdump, Wireshark; nmap (varredura de portas)
  • SPAN / monitor capture: espelhamento de porta

Segurança e gestão

  • Port-security: violation protect / restrict / shutdown (padrão); sticky aprende MACs
  • 802.1X (porta + RADIUS) · SNMP: agente, MIB, gerente (UDP 161), traps
  • HSRP (proprietário): prioridade padrão 100, preempt, track, IP virtual
